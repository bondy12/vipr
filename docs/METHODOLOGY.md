# Methodology

VIPR describes observable wallet behavior. It does not infer intent, private information, intelligence, identity, or future performance.

## Safe claims

Examples of claims that can be supported by a complete tape:

- the wallet entered within N minutes of the observed market start
- the wallet completed an exit
- realized exit multiple preserved or gave back a measured share of peak value
- one position represented X% of the sampled deployed capital

## Claims VIPR should not make

- "insider"
- "smart money" as a factual identity
- "will outperform"
- "rug puller" based only on price action
- ownership claims from a public address without separate proof

Every new metric should document denominator, minimum sample, missing-data behavior and provenance requirement.
